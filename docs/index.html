Manual installation

Ready in a few clicks.

Faster Reads is distributed directly through GitHub during beta.

Download v0.9.0 beta
  1. 1

    Download and unzip

    Extract the ZIP into a permanent folder that you will keep.

  2. 2

    Open Chrome Extensions

    Enter chrome://extensions in the address bar and enable Developer mode.

  3. 3

    Load Faster Reads

    Click Load unpacked and select the extracted folder containing manifest.json.

  4. 4

    Pin and start reading

    Pin Faster Reads from Chrome’s Extensions menu, then click its icon on any regular webpage.

Updating manually

When the extension shows an UP badge, download the new ZIP, unzip it, replace your existing extension files, then click Reload on chrome://extensions.

Verify your download with the SHA-256 checksum or GitHub build provenance.

Private by default

Your reading stays on the page.

Faster Reads has no analytics, ads, accounts, or remote code. Saved site rules and preferences use Chrome Sync. Page content is never collected.

Daily update checks are off by default and require your explicit permission. If enabled, the extension requests only the current version file from this site.
